HELI 3D v0.4.4 — TX16S MK3 / EdgeTX 2.12.2 / 모드 1/2

설치
ZIP을 풀어 SD-CARD 안의 SCRIPTS 폴더를 SD 카드 루트에 복사하세요.
최종 파일 위치: /SCRIPTS/TOOLS/HELI3D.lua
기존 HELI3D.lua를 덮어쓰고, 실행 중인 스크립트를 완전히 종료한 후 다시 실행하세요.
SYS → TOOLS → Heli 3D 700. 화면 상단 v0.4.4 표시를 확인하세요.
이전 HELISIM.lua가 아닌 HELI3D.lua를 실행해야 합니다.
조종기는 모드 1/2로 설정하고, 내부/외부 RF를 모두 끈 전용 모델에서 사용하세요.

시작 화면
왼쪽 스틱 좌우: 기체 선택
  GOBLIN RAW IL 700 / XLPOWER SPECTER V2 700
오른쪽 스틱 좌우: 속도 선택 (한 번 움직인 뒤 중앙으로 돌려놓고 다시 움직이기)
  FAST / FASTER / VERY FAST / ULTRA (왼쪽부터 점점 빠름)
모든 스틱을 중앙에 놓고 ENTER: 지상에서 비행 시작
속도와 기체는 수동 초기화 후에도 유지되며, 스크립트 재실행 시 기본값으로 돌아갑니다.
기본값: Goblin / FAST.

속도 선택
기존 v0.4.1 FAST 속도를 가장 느린 단계로 옮겼습니다.
FAST: 기존 FAST의 1.0배. 롤/플립 276도/초, 정상 호버 COL 약 +31%.
FASTER: 1.4배. 롤/플립 약 386도/초, 정상 호버 COL 약 +22%.
VERY FAST: 1.8배. 롤/플립 약 497도/초, 정상 호버 COL 약 +17%.
ULTRA: 2.2배. 롤/플립 약 607도/초, 정상 호버 COL 약 +14%.
배율은 회전 속도와 최대 콜렉티브 추력 가속에 적용합니다.
실제 이동 속도는 자세, 콜렉티브, 중력, 저항에 따라 달라집니다.
높은 단계일수록 적은 콜렉티브로도 뜨므로 천천히 올리세요.
배면 호버에서는 위 콜렉티브 값의 부호를 반대로 적용합니다.
기본 선택은 가장 느린 FAST입니다.

모드 1/2 조작
왼쪽 상하: 엘리베이터 / 플립
왼쪽 좌우: 러더 / 기수 회전
오른쪽 좌우: 에일러론 / 롤
오른쪽 상하: 콜렉티브 (중앙 0피치, 위 양피치, 아래 음피치)
오른쪽 상하를 중앙보다 위로 올려 이륙하세요.
자동 수평 복귀가 없습니다. 스틱을 놓으면 현재 기울기를 유지합니다.
배면 비행은 음피치를 사용합니다. 0피치에서는 중력으로 떨어집니다.
기존 엘리베이터 방향 수정은 유지했습니다.

카메라와 기체 크기
조종자가 지상 약 1.7m 높이에서 바라보는 시점입니다.
조종자 위치는 움직이지 않고, 헬기를 따라 좌우/위아래로 바라봅니다.
멀어지면 작아지고 가까워지면 커집니다. 가까워도 과도하게 확대하지 않습니다.
기체 표시는 가까울 때도 800px 화면 기준 로터 지름 약 114px 이내입니다.
아주 멀어졌을 때는 위치를 알아볼 최소 크기만 유지합니다.
기체가 높이 올라가면 조종자가 하늘을 올려다보므로 지면은 화면 아래로 내려갑니다.
기체 선택 화면만 모양을 보기 쉽게 비스듬한 미리보기로 표시합니다.

연속 연습
지면에 닿아도 정지나 리셋을 요구하지 않습니다. 자세를 유지하고 바로 다시 뜰 수 있습니다.
배면으로 닿으면 음피치를 주면 됩니다. 지하로 내려가는 움직임만 막습니다.
수평 이동 범위와 고도에 따른 정지/경고를 제거했습니다.
화면 갱신이 늦어져도 자동 PAUSE로 바뀌지 않습니다.
느린 프레임에서는 계산 시간을 제한하므로 시뮬레이션 시간이 실제보다 느려질 수 있습니다.

버튼
ENTER: 직접 일시정지 / 재개
재개할 때는 표시된 콜렉티브 값으로 맞추고 사이클릭/러더를 중앙에 둔 후 ENTER.
ENTER 길게: 위치와 자세를 초기화하고 기체/속도 선택 화면으로 복귀
EXIT: 비행 중 직접 일시정지, 메뉴/정지 상태에서는 종료

한계와 검증
간이 3D 물리와 자체 제작 도형입니다. 두 기체의 물리는 동일합니다.
실제 공기역학, 엔진, 로터 유입류, 오토로테이션 등을 정밀 재현하지 않습니다.
PC Lua 모의 환경에서 검증했으며 실제 조종기에서의 FPS와 화면 표시는 별도 확인이 필요합니다.
미리보기.png는 실제 Lua 그리기 호출을 PC에서 재현한 이미지이며 실기 캡처가 아닙니다.
설정 파일을 쓰거나 조종기 믹스를 수정하지 않습니다.

모드 선택 및 리버스 (v0.4.4)
시작 화면에서 ENTER를 길게 누르면 CONTROL MODE / REVERSE 설정이 열립니다.
로터리 휠 또는 +/− 버튼으로 항목 선택, ENTER로 변경, EXIT로 돌아갑니다.
SIMULATOR MODE: 원하는 MODE 1 또는 MODE 2 선택.
RADIO ACTUAL MODE: 조종기 시스템 설정의 실제 스틱 모드와 일치시킵니다.
지원되는 EdgeTX API가 있으면 자동으로 읽고, 없으면 기본 MODE 1이므로 직접 맞추세요.
조종기 시스템 설정은 변경하지 않습니다. 시뮬레이터 내부에서 세로축을 재배치합니다.
MODE 1: 왼쪽 ELE/RUD, 오른쪽 COL/AIL
MODE 2: 왼쪽 COL/RUD, 오른쪽 ELE/AIL
모드 2에서는 왼쪽 스틱 상하로 콜렉티브를 조절합니다.
AILERON / ELEVATOR / RUDDER / COLLECTIVE: NORMAL 또는 REVERSE 선택.
방향 변경은 조종기 채널 리버스가 아니라 이 설정에서 해주세요.
스틱 소스 getValue(ail/ele/rud/thr)를 직접 읽어 모델 출력 리버스/믹스를 거치지 않습니다.
설정은 스크립트가 실행되는 동안 유지되며 종료 후 다시 실행하면 초기화됩니다.
화면 오른쪽 아래 by PSP 제작자 표기가 추가되었습니다.

로터 효과음 (v0.4.4)
기본 SOUND ON. 비행 중 낮은 배경 톤으로 로터를 흉내 냅니다. 실제 헬기 녹음은 아닙니다.
콜렉티브 절댓값과 사이클릭 입력에 따라 음높이가 약간 바뀝니다.
시작 화면에서 ENTER 길게 → SOUND 항목 → ENTER로 ON/OFF.
정지나 메뉴에서는 새 소리가 재생되지 않으며 마지막 짧은 음은 최대 약 80ms 남을 수 있습니다.
음량은 조종기 Beep 음량 설정을 사용합니다. 실기 음색과 음량은 확인이 필요합니다.


견적 모드 / CRASH RESET (v0.4.4)
기본값 OFF. 시작 화면에서 ENTER 길게 → CRASH RESET → ENTER로 ON/OFF.
OFF: 지면에 닿아도 리셋 없이 계속 조종합니다.
ON: 실제 이륙 후 지면에 닿으면 시작 위치/정상 자세로 초기화하고 선택 화면으로 돌아갑니다.
스틱을 중앙에 놓고 ENTER를 눌러 다시 시작합니다. 기체/속도/모드/리버스/사운드/견적 설정은 유지됩니다.
시작 지상 대기 중에는 자동 리셋되지 않습니다. 부드러운 착륙과 배면 접촉도 이륙 후 지면 접촉이면 리셋됩니다.
스크립트를 종료했다가 재실행하면 견적 모드는 OFF로 시작합니다.
